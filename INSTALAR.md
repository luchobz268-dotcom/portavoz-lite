# Instalar Portavoz Lite

Para la persona: abre Claude Code en tu computadora y pega esta frase.

> Instala Portavoz Lite: si no tienes git, instálalo; baja https://github.com/luchobz268-dotcom/portavoz-lite.git a
> la carpeta PortavozLite de tu usuario y sigue INSTALAR.md de ahí.

---

Para Claude:

1. La carpeta es `%USERPROFILE%\PortavozLite` en Windows (si esa carpeta está adentro de OneDrive, usá
   `C:\PortavozLite`) y `~/PortavozLite` en Mac.
2. Si no está, bajala con `git clone`. Si ya está, no la bajes de nuevo.
3. Leé y seguí `.claude/skills/portavoz-instalar/SKILL.md` de esa carpeta, paso por paso. Ahí están las reglas: pedir
   permiso antes de instalar cada cosa, no pisar nada de la persona y no mostrar nunca una llave entera.
